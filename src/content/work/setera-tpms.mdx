## Overview

Setera TPMS is a hardware-interfacing utility — an Android client talking to tyre-pressure sensors over USB to read and write low-level sensor telemetry. Built at Sadguru Soft for **Setera**, a Brazilian fleet telemetry company whose product line covers vehicle tracking, CANBUS data readers, driver-monitoring cameras, and tyre temperature + pressure sensors. The interesting half of this app lives below the Flutter layer, in native Kotlin.

## Problem &amp; context

USB sensor telemetry is the kind of work where most-of-the-app is plumbing and the win is in not crashing. Pure Flutter doesn't talk to USB devices on Android — the platform exposes the APIs but they need careful native handling around permission flows, device enumeration, and stream lifecycle.

This was a B2B tool for technicians working with Setera's TPMS (tyre-pressure monitoring system) hardware in the field. The audience is small, the requirements are exacting, and the value is in the lack of surprises.

## My approach &amp; key decisions

- **Native Kotlin owns the serial protocol.** Flutter handles the technician-facing UI; the low-level read/write code stays in native land where it belongs.
- **Method Channels expose a clean Dart-side API** for the UI to call into, while keeping the serial protocol pinned to Kotlin.
- **Explicit error surfaces.** When the hardware doesn't cooperate, the technician sees what happened — not a generic failure.

## Architecture &amp; stack

- **Client:** Flutter (Dart) for the technician UI.
- **Native:** Kotlin for Android USB Host integration and the serial protocol.
- **Bridge:** Method Channels between Flutter and the native USB layer.
- **Distribution:** Setera-internal technician tool, paired with the company's TPMS sensor hardware. Brand presence at [setera.seg.br](https://setera.seg.br/); not on public app stores.

## Challenges

- **USB device permission and lifecycle on Android.** Enumeration, attachment events, permission requests, and stream cleanup — none of it is forgiving.
- **Serial protocol reliability.** Sensor telemetry over serial is unforgiving about partial reads and timing.

## Results &amp; impact

- Setera-internal technician tool paired with the company's TPMS sensor lineup. Not on public app stores; brand presence at [setera.seg.br](https://setera.seg.br/).
- Setera's broader product range — visible on the brand site — covers fleet telemetry (STR-1010+), CANBUS data readers, tyre temperature + pressure monitoring, driver-monitoring cameras with facial recognition, and jamming-detection / anti-vandalism automatic-blocking systems. This app sits in the TPMS slice of that lineup.
